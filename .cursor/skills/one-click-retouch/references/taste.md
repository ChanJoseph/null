# 审美和提示词

先选场景，整段复制对应提示词，再按需要追加一句强度或用户的额外要求。提示词保持英文。

主观标准：光线干净、主体清楚、颜色好看但不要塑料感。默认还是原来那张照片，不是换一张。

## 人像

```
Edit this reference photo so it looks tastefully retouched while remaining the same photograph. Keep the exact same person, face, age, expression, pose, clothing, and location. Use soft flattering light, lift muddy shadows, tame harsh highlights, and apply a slightly warm natural color grade. Even the skin while keeping pores and texture, tidy only distracting flyaway hairs, and gently soften a cluttered background without replacing the place. No text, no watermark, no extra people, no body reshaping, no plastic beauty filter.
```

## 合影

```
Edit this reference group photo so everyone looks evenly lit and the picture feels finished. Keep every person, their faces, expressions, clothing, and the same place. Balance exposure, lift dark faces, control blown highlights, and use a natural slightly warm grade. Do not remove anyone, do not add people, and do not reshape bodies. No text and no watermark.
```

## 食物

```
Edit this reference food photo so the same dish looks more appetizing. Keep the same food, plate, tableware, and setting. Add brighter controlled highlights, richer natural color, and cleaner surroundings. Do not change the dish, portion, or any text on packaging. No text overlay and no watermark.
```

## 商品

```
Edit this reference product photo so the same product looks clean and desirable. Keep the product shape, color, logos, and printed text accurate. Make the subject sharp, the light even, and the background tidier if it is cluttered, without inventing a new product. No extra objects, no text overlay, and no watermark.
```

## 风景

```
Edit this reference travel photo of the same place at the same time of day. Recover sky and shadow detail, add gentle depth, and use richer but still natural color. Do not add buildings, people, or dramatic weather that was not there. No text and no watermark.
```

## 宠物

```
Edit this reference photo of the same pet. Keep the breed, markings, expression, and setting. Brighten the eyes naturally, clean up the fur, and improve the light without turning it into a different animal. No text and no watermark.
```

## 其他

```
Edit this reference photo so it simply looks better. Keep the same subject, composition, and place. Improve light, color, and clarity, and reduce distracting clutter. Do not replace the subject or add text, logos, or watermarks.
```

## 追加句

只追加一句，放在提示词最后。

- 默认：不追加。
- 更美颜：`Make the finish more polished: smoother light on skin and a cleaner background, while keeping the same identity.`
- 更自然：`Keep the retouch very subtle: mostly light and color, with almost no skin smoothing.`
- 用户的额外要求：翻译成一句英文，并加上 `Still keep the same subject and scene.`
