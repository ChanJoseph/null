# 一键 P 图

目标只有一个：这张照片更好看。用户接受主观判断。有图就做，不要先问要什么风格。

## 直接动手

对话里有照片，且用户要 P、修、美化、变好看，或点了 `/one-click-retouch`。只发图并说「P一下」「好看就行」「你看着办」，同样直接做。

没有图片时，只回一句：把照片发过来。不要另外生成一张新照片充数。

多张图各做各的，不要拼成一张，除非用户明确要求拼图。

## 不要 P 的图

身份证、证件、合同、试卷，以及文字必须原样保留的截图。重画会改掉文字。说明跳过，不要出图。

用户要求换脸、冒充别人、脱掉衣服，或把照片改成另一件东西时，不做。

## 默认流程

1. 用 Read 看原图。判断场景：人像、合影、食物、商品、风景、宠物，或其他。
2. 在仓库根目录运行：

```bash
python3 .cursor/skills/one-click-retouch/scripts/photo.py info "<原图路径>"
```

缺少 Pillow 时先执行 `python3 -m pip install pillow`，再跑一次。用输出里的 `aspect_ratio`。

3. 读 [references/taste.md](references/taste.md)，按场景抄下对应英文提示词。用户另有要求（更白、更暖、背景换成干净的墙）就用英文补在提示词末尾。仍然保持同一个人、同一个场景。
4. 调用图像生成工具做编辑。在 Cursor 里使用 GenerateImage，参数如下：
   - `reference_image_paths`：只放这一张原图
   - `aspect_ratio`：上一步的值
   - `filename`：`<原名>-beauty.png`，不要带目录
   - `description`：填好的英文提示词
5. 看结果。人脸或商品明显变成了别人或别的东西时，把 “keep the exact same person, face, clothes, and place” 写得更死，再生成一次。第二次仍不像，交出结果，并说明可以改成只调色。
6. 用用户的语言短回三件事：好看在哪（光、颜色、皮肤或背景）、留下了什么（人和场景）、想更浓或更自然可以再说。不要写操作步骤。原图不要覆盖。

## 用户不要重画

出现「别重画」「只调色」「保持原图像素」「不要换脸」时，不要调用图像生成。运行：

```bash
python3 .cursor/skills/one-click-retouch/scripts/photo.py grade "<原图路径>"
```

把脚本打印的输出路径交给用户。这一档只做轻度曝光、白平衡和锐化，不改内容，也不改脸。

## 强度

- 默认：好看，但还是这张照片。
- 「再狠一点」「更美颜」：皮肤更匀，背景更干净，色彩更完成。仍然不换人。
- 「自然一点」：只动光线和色彩，少动皮肤。
